## Overview

**Page Purpose:** 盘点当前 per-track XP 派生的已解锁 AWS 服务牌集 + 各牌配额 + 选定关准入（`required_cards ⊆ unlocked_cards`，source-agnostic guard 派生显示），据此判断「能组什么、这关要的牌够不够」。只读页，不写。
