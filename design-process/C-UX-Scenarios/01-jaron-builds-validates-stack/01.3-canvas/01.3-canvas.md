## Overview

**Page Purpose:** 从 01.2 牌池进入选定关卡的画布实例（#4 instance，如 W1 静态站）。拖 AWS 服务牌到 ASCII 画布组装架构栈 -> 「提交校验」CTA（**手动提交，决策 A**）触发双层校验（A3 句法 floor + B1 多参考语义匹配 + B3 WA 分阈值）-> 看结果 overlay（命中参考架构 / 缺失 edge / 未过阈值 trace）。sunshine = 过关；不过 = on-page retry（不离开、不分支）。= 核心判断闭环页，轴A正「合理框架判断」练习载体。

**Entry Context:** 从 01.2 牌池点「进入画布 / 开始组装」CTA 进入。进关时 #4-entry guard enforce 准入（`required_cards ⊆ unlocked_cards`，source-agnostic）。

**Exit Action:** 提交校验过 A3+B1+B3 -> overlay 显过关 + WA 分 -> 点「继续 / 领 XP」CTA -> 进 #6 XP/进阶(01.4)。XP 由 #6 记录（CS6 权威），画布只产判定 + WA 分。

**On-Page Interactions:**
- 拖牌从牌池到 ASCII 画布放置 / 移除 / 连接 edge
- 「提交校验」CTA 触发 A3+B1+B3（手动，决策 A；非自动即放即校验）
- 不过：on-page retry（调整栈再提交，不离开）
